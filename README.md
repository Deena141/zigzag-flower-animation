# 🌸 Zigzag to Flower Animation

A small creative Python project that transforms multiple
zigzag lines into a colorful flower animation.

## ✨ Features

- 🔴 Red, pink and orange colored lines
-〰️ Animated zigzag movement
- 🌸 Smooth transformation into a flower
- 🔄 Continuous animation loop
- 📊 Created using Python and Matplotlib

## 🛠️ Technologies Used

- Python
- NumPy
- Matplotlib
